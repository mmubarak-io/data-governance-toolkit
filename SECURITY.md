# Security

This repository ships documents and templates, not running software, so the usual
vulnerability surface is small. Two things are still worth reporting privately.

## What to report privately

- **Personal data that looks real.** Every example here is meant to be synthetic. If
  something looks like a real record - a name, an Emirates ID, an IBAN, an email that
  resolves - report it privately rather than opening a public issue.
- **Anything that looks organisation-derived.** Content that appears to come from a
  specific company's internal documents does not belong here.

## How

Use [GitHub private vulnerability reporting](https://github.com/mmubarak-io/data-governance-toolkit/security/advisories/new)
on this repository. Please do not open a public issue for either case above.

For ordinary errors - a wrong article reference, a stale date, a broken link - a public
issue is the right place.

## Scope note

The fillable `.xlsx` and `.docx` files contain no macros. If you receive a copy that
does, it did not come from here.
